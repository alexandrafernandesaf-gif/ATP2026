Este programa consiste numa aplicação interativa desenvolvida em Python para a criação, análise e manipulação de uma lista interna de números inteiros através de um menu de opções em ciclo. O sistema permite ao utilizador inicializar a lista gerando valores inteiros aleatórios entre 1 e 100 ou inserindo manualmente os elementos desejados, substituindo a lista anterior sempre que uma destas opções é selecionada. A partir da lista guardada, a aplicação disponibiliza ferramentas para calcular a soma e a média dos seus elementos, determinar o maior e o menor valor presente, verificar se a sequência se encontra ordenada de forma crescente ou decrescente, e pesquisar a posição de um determinado número, devolvendo a respetiva posição ou o valor -1 caso o elemento não seja encontrado. O programa executa continuamente as operações solicitadas, reexibindo o menu após cada ação até que o utilizador escolha a opção de sair, momento em que a aplicação termina a sua execução mostrando a lista final mantida em memória.
